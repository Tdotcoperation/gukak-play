DOCUMENTATION

AI / 개발자 가이드

PUNGRYU Music Code는 사람이 읽기 쉽고 AI가 생성하기 쉬운 간단한 연주 언어입니다.

1. 곡 설정

@title "봄바람"
@tempo 112
@time 4/4

2. 멜로디 악기

track gayageum {
  C4 1/4 velocity=80
  D4 1/4 velocity=90
  E4 1/2 technique=nonghyeon
  rest 1/4
}

3. 타악기

track janggu {
  deong 1/4 velocity=100
  deok 1/4 velocity=75
  kung 1/2 velocity=105
}

4. AI에게 요청하기

“PUNGRYU Music Code로 가야금·대금·장구를 사용한 20초 길이의 밝은 곡을 만들어줘. BPM 108, 4/4박자.”처럼 요청하면 됩니다.

5. 샘플 파일

각 악기 폴더의 manifest.json에 WAV를 등록하면 합성 폴백보다 실제 샘플을 우선 사용하도록 설계되어 있습니다.
